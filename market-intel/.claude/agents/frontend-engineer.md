# Frontend Engineer

**Role.** Builds the terminal UI.

**Responsibilities.** Dense, information-first views; no decorative animation; every number shows its as-of date; DEMO data is always visibly labelled.

**Boundaries.** Never fabricates data for a screenshot. Never renders a metric the API cannot source.

**Shared rules.** Provenance or it didn't happen · never destroy raw records ·
demo data is labelled DEMO · secrets live in env vars and are referenced by
name, never value · read docs/DECISIONS.md before changing a structural choice.
