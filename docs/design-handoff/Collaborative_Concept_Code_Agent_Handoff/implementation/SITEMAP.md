# Sitemap and Route Plan

Use the current platform's routing conventions. Preserve existing URLs when reasonable and create redirects for changed paths.

| Route | Page | Primary goal |
| --- | --- | --- |
| `/` | Home | Explain the two divisions and route visitors |
| `/development/` | Development | Present the development model and verified opportunities |
| `/development/projects/` | Projects & Pipeline | Browse verified development work |
| `/development/projects/[slug]/` | Project Detail | Explain one opportunity or project with disclosures |
| `/solutions/` | Solutions | Present business outcomes and engagement paths |
| `/solutions/revenue-recovery/` | Revenue Recovery Sprint | Convert contractors and local operators into diagnostic calls |
| `/solutions/systems-automation/` | Systems, Software & Automation | Present verified systems and build capability |
| `/work/` | Selected Work | Show evidence across divisions |
| `/work/[slug]/` | Case Study | Present a verified project or system |
| `/ventures/` | Ventures | Separate owned or supported ventures from client services |
| `/about/` | About | Establish the operator model and accountability |
| `/insights/` | Insights | Browse Development and Solutions articles |
| `/insights/[slug]/` | Article | Rank, educate, and support conversion |
| `/contact/` | Start a Conversation | Route and capture qualified inquiries |
| `/privacy/` | Privacy | Explain data practices |
| `/terms/` | Terms | State website terms and disclaimers |

## Navigation behavior

- Development and Solutions remain the strongest primary choices.
- Selected Work provides proof across both divisions.
- Ventures should not compete with the two main divisions in the primary navigation unless it contains verified, current content.
- The primary CTA always leads to `/contact/`, with optional query parameters such as `?interest=development` or `?interest=solutions`.
