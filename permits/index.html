How this works. The backend pulls permits straight from each jurisdiction's public GIS feeds, auto-maps each one's schema (by field name, then by the actual data when names don't match), and tags every permit by project type — same pipeline shape as commercial permit-data vendors, scoped to South Florida. Owner lookup links go to each county's property appraiser (free). The CSV export is shaped for direct upload to a skip-trace service for phone/email append.
Coverage (honest): Miami-Dade — full countywide issued-permit feed with ~2 years of history (county open data). Broward — issues per-municipality; Fort Lauderdale + Pembroke Pines + unincorporated county are wired in (add more cities via the PERMITS_EXTRA_SOURCES env var). Martin — no GIS feed; the engine scrapes the county's Accela permit portal directly for issued building permits, plus the county's development-projects layer as a supplement.
Code Violations — Miami-Dade RER's open code-enforcement cases (unsafe structures, liens, unpermitted work) are pulled as a distinct category (filtered to open cases only) — high-intent distressed-property / structural-repair leads. Use the data-type dropdown to show permits, violations, or both. Palm Beach — the county and its cities run permits through Accela / Click2Gov portals and publish no queryable permit feed; the engine auto-activates one the moment that changes.
Compliance: permits are public records, but cold calls/texts to enriched contacts fall under TCPA / FTSA and DNC rules — direct mail and door-knocking are the low-risk channels.
