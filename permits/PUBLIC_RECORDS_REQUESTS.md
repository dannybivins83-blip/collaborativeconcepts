# Public-Records Requests — Unincorporated County Permit Data

These two requests obtain the bulk building-permit data that has **no public
online feed** — the unincorporated areas of Palm Beach and Broward counties.
Florida's Public Records Act (Chapter 119, F.S.) requires agencies to provide
existing records, including database exports, at no more than the actual cost
of duplication.

**How to send:** email each to the address below (or submit via the county's
online records portal). Both counties have online request forms — links under
each request. A recurring monthly export is often granted if you ask for it.

---

## 1) Palm Beach County

**To:** Palm Beach County Planning, Zoning & Building Department — Public Records
**Email:** pzbpublicrecords@pbc.gov  (or submit at https://discover.pbc.gov/ → Public Records)
**Subject:** Public Records Request — Building Permit Data Export (Unincorporated PBC)

Hello,

Under Chapter 119, Florida Statutes, I am requesting an electronic export of
building-permit records issued by Palm Beach County for the **unincorporated
areas** of the county (and any municipalities the County permits under contract).

**Records requested:** all building permits **applied for or issued from
January 1, 2024 to the present**, with the following fields for each permit:

- Permit / record number
- Permit type and description (scope of work)
- Site address, city, and ZIP
- Parcel Control Number (PCN)
- Application date and issue date
- Current status
- Declared / estimated job valuation
- Contractor name and license number (if maintained)
- Property owner name and mailing address (if maintained in the permit record)

**Format:** please provide as a **CSV or Excel (.xlsx) file**. A database export
is preferred over PDFs.

**Recurring:** if feasible, I would also like to arrange a **recurring monthly
export** of newly issued permits going forward. Please let me know the process.

Please advise of any duplication cost before processing if it exceeds $25. I am
happy to receive the file by email or download link.
